## Integration contract

```js
import {definitions as prCards} from './night-shift-v3/scenes/pr/index.js';
// Merge into the global 16-card registry without modifying the four canonical IDs.
const card = prCards.find(d => d.id === nextCardId);
const scene = card.create({viewport, events, audio, run, options});
scene.enter();
// Each unpaused frame:
scene.update(dtSeconds);
scene.draw(ctx2d, viewport);
// All pointer events must use viewport.screenToWorld; pass {x,y,id,kind}.
```

P4 expects `context.run.miraIncident` or a recorded `mira-spill`/`mira-saved` event (if neither, stage says **NOT OBSERVED**). `card-complete` is the only finalisation event. The emitted evidence `effect` for P4 must be consumed exactly once by SYSTEMS, *not* automatically granted by this scene. It is `{type:'priority-pass',uses:1,target:'next-staff-card'}` or `{type:'quota-warning-card',leadSeconds:.6,uses:1,target:'the-quota'}`. Optional `context.audio.play('hit'|'miss'|'card-win'|'card-fail')` is injected by AUDIO.

## Known limitations and ownership boundaries

- The live full game, HD reference and AUDIO/ART/RENDER integrations are unfinished on this branch. This preview is a standalone scene validation, **not** a release candidate or evidence of passing all visual/audio gates.
- Current Finch is original primitive art, but the eventual ART lane animation asset should replace/supplement it after a real side-by-side with HD. Background paper grain, character expression range and audio mix need a full-system visual acceptance.
- Popup cover is a visible thrown obstruction with kinematic bounce and optional `popup-cover` event, not a Planck.js rigid body. If LEAD wants simulated cover collisions in the final combined game, the PHYSICS lane should expose compatible throw-body hooks instead of this lane editing their owned code.
- Timing targets are authored and deterministic; playtest pacing is **unverified with humans**. Current preview allows any card to be selected for testing, while the RUN/SYSTEMS lane owns selecting P1, P4 and P2-or-P3 for a 12-card shift.
- Browser QA screenshots stay in the local working folder unless attached separately; screenshot file paths and audit results are truthful, not fabricated GitHub artifacts.

**Do not merge blindly on green tests.** Compare real rendered game and intermission with HD, reject regressions, keep the HD fallback intact.
