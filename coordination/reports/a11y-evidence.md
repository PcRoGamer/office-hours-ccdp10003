# Night Shift v3 | supplemental QA_A11Y evidence

**Lane:** `QA_A11Y`, an explicitly supplemental role because all 17 listed lanes and PERF had already been claimed. **Branch:** `agents/v3-qa-a11y-g6-62f91`. No other lane's source or release was edited.

## Shipped

- `qa/v3-a11y-audit.py`: actual Playwright/Chromium probe for responsive Canvas2D coverage, DPR backing, keyboard focus/Clock In, pause-clock freeze, `M` mute state, safe pointer cancellation, deliberately authored QA hit target, reduced-motion state, colour-independent cue review, browser errors; generates JSON, Markdown and real captured frames. `REVIEW` is not a pass and `UNAVAILABLE` is a hard error. No invented coordinates or game-specific hooks.
- `qa/v3-a11y-selftest.py`: four viewport/DPR smoke runs, 9 explicit assertions per viewport, strict-mode refusal to treat manual checks as green, absent-target rejection. Requires Python Playwright and Chromium.
- `previews/v3-a11y-fixture.html`: a standalone interactive Canvas2D input verification *fixture*. This is intentionally **not** a proposed v3 card or final game asset.
- `qa/v3-a11y-fixture-*.webp`: small annotated-by-filename thumbnails downscaled from actual Chromium screenshots for reviewer convenience; full-res PNG captures are generated by the audit.

**True provenance:** the Chromium installation in the execution environment has an administrator policy with `URLBlocklist: ["*"]`, so attempts to open both `http://127.0.0.1:4173` and a local `file://` document returned `ERR_BLOCKED_BY_ADMINISTRATOR`. Playwright `page.set_content` successfully rendered/exercised the *self-contained fixture* in actual Chromium. Normal HTTP navigation is used by the production audit and must be run in a browser without this policy. The full v3 route and HD reference were **not** inspected in a live browser from this environment. No production visual or audio pass is claimed.

## Visual inspection cycle

Inspected real Chromium frames at desktop 1440×900 and narrow 650×800. The fixture has a page-filling stage, a keyboard focusable Clock In button, viewport-anchored HUD and a visible paper interaction target without narrow clipping. The initial audit could not launch Chromium's missing packaged browser; changed it to use an installed system Chromium when available. Navigation was then policy-blocked; added strictly marked fixture-only document injection, which rejects baseline use to prevent misleading results. Retested and visually inspected. The preview is a *diagnostic lab*, not a replacement for HD character performance, music, artistry, or full GDD.

## Run on actual integrated game and HD

```bash
python -m http.server 4173
python qa/v3-a11y-audit.py \
  --url http://127.0.0.1:4173/night-shift-v3.html \
  --baseline http://127.0.0.1:4173/arcade-office-hd.html \
  --start-world 220,605 \
  --out qa-artifacts/v3-a11y-live
```

The explicit `--start-world` point is from existing HD browser test conventions; target v3 should prefer an accessible Clock In control. If a state or safe target cannot be observed, the audit marks it `REVIEW`, not `PASS`. Verify full screenshots, audio output, high-contrast shape cues, and reduced-motion shake suppression manually. No game implementation code is altered by this QA lane.

## Integration recommendation / limitations

LEAD can import this independent QA tool without runtime changes. For better non-invasive observability, optionally expose a **read-only** `window.__nightShiftV3.snapshot()` with `screen`, `clock`, `muted`, `dragging`, `options.reducedMotion`, and only safe authored `qaTargets` in CSS pixel coordinates. All fields are optional; missing fields produce actionable `REVIEW` rather than a false success. Defer any runtime interface decision to its owning lane.
